# Город. Дизайн. Код.

Лендинг бесплатного вебинара Городского университета 2.0 о дизайн-коде города. Статичная страница без сборки: `index.html`, `styles.css`, `script.js`, картинки в `img/`.

## Сбор заявок в Google Таблицу

1. Создайте Google Таблицу.
2. В ней: **Расширения → Apps Script**, вставьте код из [`google-apps-script/Code.gs`](google-apps-script/Code.gs), сохраните.
3. **Развернуть → Новое развертывание** → тип «Веб-приложение», «Запуск от имени: я», «У кого есть доступ: все» → разрешить доступ.
4. Скопируйте URL веб-приложения (заканчивается на `/exec`) и вставьте в `script.js` в константу `SHEET_URL`.

Заявки попадают на лист «Заявки»: дата, имя, email, согласие, страница.
